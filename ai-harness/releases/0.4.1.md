# AI Harness 0.4.1

Corrige la evolución de tareas bloqueadas y formaliza el avance dinámico
gobernado.

- El control detecta bloqueos obsoletos cuando todas las dependencias están
  `done` y no quedan decisiones pendientes.
- La transición se deriva como `PROMOTE`/`NONE`; el control permanece read-only
  y nunca modifica el backlog ni inicia la tarea.
- El reporte incluye vistas generales y por producto desde una única cola.
- El orden de gobierno se aplica también a las promociones derivadas.
- `DEC-010` reserva a personas las decisiones de producto, prioridad, alcance,
  excepciones, operaciones destructivas/remotas y releases de alto riesgo.
