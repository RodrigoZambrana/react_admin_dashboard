# AI Harness 0.6.0

Hace verificable la fidelidad entre un pedido y el backlog canónico.

- El schema `ai-harness.intake/v1` captura necesidad, requisitos, clasificación
  y slices terminables.
- `harness:intake` comprueba pérdida o mezcla de requisitos y emite diffs
  semánticos requisito→tarea.
- Las preguntas humanas sin respuesta bloquean el cierre del intake; inferirlas
  falla.
- Las vistas general y por producto se derivan de `planning/backlog.json`.
- La promoción `blocked → ready` se propone con los mismos gates que el control
  y solo se escribe con confirmación explícita, sin iniciar trabajo.
