# AI Harness 0.7.0

El harness escribe las promociones mecánicas `blocked → ready`.

- `DEC-012` supersede solo la consecuencia de `DEC-010` que prohibía mutar el
  backlog para ese cálculo.
- `apply-promotion` escribe sin `--confirm`; `--dry-run` previsualiza;
  `--start` permanece prohibido.
- `lifecycle close` promociona sucesores elegibles y sincroniza el fragmento
  dueño cuando está en el write-set.
- El control y el auditor no escriben el backlog ni piden a una persona que
  confirme el DAG. El arranque sigue siendo `lifecycle start` o un chat nuevo.
