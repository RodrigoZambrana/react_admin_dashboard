# AI Harness 0.5.0

Hace del commit local una condición atómica del cierre gobernado.

- `close` usa un index aislado para comprometer solo el candidato validado y los
  artefactos finales.
- La tarea no queda `done`/`idle` hasta crear y verificar el commit.
- Cambios ajenos y contenido staged preexistente se preservan sin incorporarse.
- El journal permite restaurar HEAD, index, working tree y autoridades si el
  commit falla o el proceso se interrumpe.
- Los recibos v2 describen cómo comprobar el candidato comprometido.
- No se hace push, merge, cambio de branch ni ninguna operación remota.
