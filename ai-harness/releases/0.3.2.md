# AI Harness 0.3.2

Completa el handoff del Chat de Auditoría y Control. Cada recomendación indica
uno de estos destinos:

- `NEW_CHAT` para iniciar una tarea `ready` en un chat de implementación nuevo;
- `CONTINUE_EXISTING_TASK` para retomar la sesión de implementación activa;
- `NONE` cuando el control bloquea cualquier ejecución.

Cuando existe una recomendación ejecutable, la sexta sección incluye
íntegramente `recommendation.prompt.content` en un bloque `text` copiable. El
validador comprueba el destino y la igualdad exacta del prompt con el reporte
fuente; el chat auditor nunca ejecuta ese handoff.
