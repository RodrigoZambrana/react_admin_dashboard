# AI Harness 0.4.0

Incorpora lifecycle gobernado y preflight Git como mecanismos ejecutables.

- `start` valida una única tarea elegible y conserva baseline, branch,
  worktree, tarea, alcance, cambios preexistentes y write-set.
- `preclose` requiere evidencia positiva para toda la aceptación y
  verificación, y genera un recibo del diff permitido.
- `close` comprueba que el candidato no cambió y actualiza todas las fuentes de
  verdad y recibos en una única transacción.
- El journal por checkout permite rollback inmediato y recovery después de una
  interrupción, también dentro de linked worktrees.

No crea commits, no cambia branches, no usa stash, no resuelve conflictos ni
integra remotos.
