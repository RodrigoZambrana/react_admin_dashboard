# AI Harness 0.3.0

Incorpora `harness-control`, un perfil read-only inspirado en el control del
harness académico y adaptado al portfolio Growth Platform.

El reporte reconstruye Git, backlog, requerimientos, decisiones, capacidades y
guardrails desde fuentes locales. Separa hechos, discrepancias, decisiones
humanas y recomendaciones derivadas; ante inconsistencia no expone una próxima
acción ejecutable.

Esta versión no declara paridad con LACNIC: registra capacidades implementadas,
parciales, planificadas y no aplicables para cerrar la brecha con evidencia.
